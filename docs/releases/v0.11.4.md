# 0.11.4 — Configurable Live Activity first-line length

- Adds a per-child maximum character count for the first body line (24–60,
  default 28) under Configure → Live Activity.
- Shortens the current subject first, retaining room and end time. The next lesson
  line remains unchanged. At very small limits, the time label is omitted before
  shortening an exceptionally long room label.
- Uses a shorter timetable-unavailable message so the status stays readable.
- Documents the setting in English and Dutch and in the README. Silent updates,
  subject icons and full calendar export descriptions remain unchanged.

Update in HACS and restart Home Assistant. Existing configurations use 28 characters.
Adjust the limit for your phone's font size; character count is not a pixel-width guarantee.
