# 0.11.3 — Less repetition for consecutive lessons

- When the upcoming lesson starts exactly as the current lesson ends, the upcoming
  line omits the repeated start time: `Hierna: Nederlands` / `Next: Nederlands`.
- A gap between lessons still shows the upcoming start time. The current end time
  and next classroom remain visible.
- Known lowercase subject names use consistent display capitalization in the Live
  Activity. Original source titles and calendar exports remain unchanged.
- Updates the README introduction to the current stable features and version.

Update in HACS and restart Home Assistant. Existing activity identity and title
remain unchanged; no reconfiguration is required. Silent updates from 0.11.2 remain
enabled.
