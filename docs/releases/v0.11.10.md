# v0.11.10 — child-safe homework, faster polling and easier sign-in

- **Parent accounts with multiple children:** study-guide tests/homework are attributed to a child only when `additionalObjects.leerlingen` explicitly includes that pupil. If owner information is missing or malformed, the snapshot is treated as incomplete instead of accidentally copying a sibling's work or deleting existing calendar/to-do entries. Single-child behavior remains compatible. Fixes #16; supersedes PR #14.
- **Optional Chrome/Edge helper:** Manifest V3 source extension in `login_helper/` to capture Somtoday redirects in browser session memory, fill the Home Assistant callback field, and offer a clipboard fallback. Authentication remains available without the helper. Related to #11, #2, #15 and #19.
- **Optional variable polling:** normal 15-minute polling is preserved by default. An opt-in local-time window can poll every 5 minutes from 07:00 to 08:00 or at other configured whole-hour boundaries. Overnight windows supported. Related to #4.
- Updated Dutch/English configuration translations, sign-in safety guidance and regression tests.

The helper requires manual unpacked installation and may need the clipboard fallback depending on browser/HA UI. API pupil ownership on guardian accounts should be confirmed against a real multi-child account. Update in HACS and restart or reload the integration.
