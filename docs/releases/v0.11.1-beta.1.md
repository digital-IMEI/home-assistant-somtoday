# 0.11.1-beta.1 — Appointment type investigation

Test build to investigate separate proefwerk appointments missing from the tests
calendar. This build exposes original appointment classification metadata on each
child's timetable calendar. It does not change test recognition or calendar exports.
It also includes the previously prepared Android Live Update support, authentication
recovery fixes and grouping of entities under per-child devices.

After installing and restarting Home Assistant, open Developer Tools > States and
select `calendar.seth_rooster`. The `appointment_debug` attribute lists the original
title, time, status, subject presence, appointment type name/category/activity and
available scalar colour fields. Missing fields remain empty rather than guessed.
The list is limited to the first 100 loaded appointments per child; the total and
truncation flag are also shown.

Copy the row for the green proefwerk appointment and the simultaneous blue lesson.
This lets us compare their original classification independently of displayed colour.
Titles and times appear only in the local calendar entity, not in downloadable
diagnostics. Source IDs, links, descriptions and student records are excluded.
