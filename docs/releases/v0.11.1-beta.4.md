# 0.11.1-beta.4 — Clear current and upcoming lesson labels

- Fixed title: **Name · Next room** / **Naam · Volgend lokaal**. The room on the
  right belongs to the upcoming lesson.
- Body text contains no emoji or decorative icons. Only the left main icon changes
  for subjects, breaks and the start/end of the school day.
- Consistent body order: **Now:** current subject, current room and end time;
  **Next:** upcoming subject and start time. Lines no longer swap in the final five minutes.
- During breaks, the first line gives the break end time and the second identifies
  the upcoming subject. The next room stays on the right.
- Android also includes the next room in the body for layouts without a right-hand field.
- Missing rooms are explicitly identified. No next lesson shows a dash on the right.
- Existing cards from the previous layout are ended and recreated once so their
  creation-only title changes too. Failed clears retry before creating a replacement.

Install via HACS beta versions and restart Home Assistant. The existing Live Activity
switch can stay enabled. HTML fixes, transparent iOS background and Somtoday app links
from beta.3 are retained. Final phone rendering remains a device check.
